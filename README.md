# 현대병기 · 중세회귀 디펜스

중세로 떨어진 병기 개발자가 **나쁜 군주의 대군**을 현대 화력으로 막아내는 물량 디펜스 게임입니다.
성벽 앞에서 직접 사격하고, 포탑과 바리케이드로 방어선을 세우고, 웨이브를 버틴 보상(설계도 📘)으로
연구소에서 새 무기를 영구 해금합니다.

**▶ 플레이: https://bbangdenge-314.github.io/modern-defense/**

- 장르: 2.5D 야간 물량 디펜스 (탑 디펜스 + 슈터)
- 한 판 길이: 15 웨이브, 약 12~20분
- 플랫폼: PC(키보드+마우스) / 모바일(터치), 설치·로그인 없음
- 저장: 브라우저 localStorage (설계도·해금·영구 강화 유지)

---

## 조작법

### PC
| 입력 | 동작 |
| --- | --- |
| 마우스 이동 / 클릭 유지 | 조준 및 연사 |
| `WASD` / `←` `→` | 성벽 앞에서 좌우 이동 |
| `1` ~ `9` | 해금한 무기로 교체 |
| `R` | 재장전 (탄창이 비면 자동 재장전) |
| `Q` / `E` | 수류탄 / 집속 포격 → 발동 지점 클릭 |
| `B` / `V` / `N` / `M` | 센트리 / 화염 포탑 / 박격포 / 바리케이드 건설 |
| `F` | 자동 조준 ON/OFF |
| `S` | 1× / 2× 배속 |
| `Space` | 일시정지 |
| `Esc` | 모드 취소 → 모달 닫기 → 일시정지 |
| `U` | 무기 강화 창 |

### 모바일 (390×844 검증)
- **전장 탭**: 조준·사격, 스킬/건설 모드에서 탭한 지점에 발동·설치
- **화면 좌우 ◀ ▶**: 이동
- **하단 독**: 무기 슬롯(가로 스크롤), 건설 버튼, 수류탄/집속포격/자동조준, 무기 강화, 다음 웨이브
- **상단**: 웨이브 진행·적 편성 미리보기, 마을 방어선(성벽) 체력, 골드/고철/설계도, 배속·일시정지·설정

---

## 방어선과 자원

- **성벽(마을 체력)**: 적이 도달하면 깎입니다. 0이 되면 패배. 상단 `긴급 수리 60🪙`로 즉시 회복할 수 있고, 웨이브를 막으면 최대치의 6%가 자동 회복됩니다.
- **바리케이드**: 적의 진로를 막고 대신 맞아 줍니다(내구도 520). 최대 12개.
- **🪙 골드**: 포탑·바리케이드 건설, 수리. 적 처치와 웨이브 보상으로 획득.
- **⚙️ 고철**: 전투 중 무기 임시 강화. 적 처치로 획득.
- **📘 설계도**: 영구 재화. 웨이브 클리어마다 획득, 연구소에서만 사용.
- 포탑은 바닥의 **원형 설치 패드**에만 지을 수 있습니다(PC 8개 / 모바일 6개). 설치된 포탑을 누르면 강화(Lv.1→5) · 철거(건설비 50% 환불) 창이 열립니다.

| 공성탑 | 최고 내구도, 방어선 붕괴 주범 |
| **악덕 군주** | 15 웨이브 보스. 주기적으로 지면 강타(주변 구조물 파괴) |

## 웨이브와 난이도

- 총 **15 웨이브**. 15 웨이브를 모두 막으면 승리, 성벽이 무너지면 패배.
- 웨이브 사이 24초 준비 시간에 `다음 웨이브`로 바로 시작할 수 있습니다.
- 난이도 **보통 / 어려움 / 지옥**: 적 체력·물량·설계도 보상이 달라집니다(지옥은 적 체력 ×2.05, 설계도 ×1.8).

## 연구소 (영구 성장)

- **무기 해금**: 9종 무기 + 레일 포탑
- **영구 강화**: 포탑 화력 +12%/Lv, 성벽 최대 체력 +450/Lv, 시작 골드 +80/Lv, 골드·고철 획득량, 스킬 재사용 대기 -10%/Lv
- **진행 관리**: 최고 기록 확인, 진행 초기화(2단계 확인)

빌드 과정이 없는 정적 사이트입니다. 폴더를 그대로 열거나 로컬 서버로 실행하세요.

## 검증 메모

- Chromium(Playwright) 1440×900 PC / 390×844 터치 모바일에서 실제 플레이 검증, 콘솔·페이지 에러 0건.
- 확인 항목: 게임 시작→난이도 선택, 사격·적 처치·피격, 포탑 4종·바리케이드 건설, 포탑 강화·철거,
  성벽 긴급 수리, 인게임 무기 강화, 스킬(수류탄·집속 포격), 자동 조준, 배속·일시정지,
  연구소 무기/포탑 해금·영구 강화·진행 초기화, 결과창(승리·패배)→연구소→복귀, 저장 유지.
- 모바일에서 상단 자원 바가 방어선 카드와 겹치고 하단 독이 잘리던 문제를 수정했습니다.

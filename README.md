# 현대병기 · 중세 방어전

중세로 회귀한 병기 개발자가 **현대 화력으로 마을을 지키는 쿼터뷰(2.5D 아이소메트릭) 물량 디펜스**입니다.
They Are Billions처럼 사방에서 수백~수천의 중세 군대가 몰려오고, 마을 성벽 안팎의 방어 슬롯에
개틀링·박격포·레이저·레일건을 세워 막아냅니다. 기술 트리, 재회귀 영구 강화, 고대 유물, 시네마틱 스토리까지.

**▶ 플레이: https://bbangdenge-314.github.io/modern-defense/**

- 장르: 아이소메트릭 물량 디펜스 (타워 디펜스 + 기지 방어)
- 플랫폼: PC(마우스·키보드) / 모바일(터치), 설치·로그인 없음
- 저장: 브라우저 `localStorage` — 회귀석·유물·기록은 영구 보존

## 스토리

37번째 시제품 테스트 중이던 병기 개발자 **한도현**은 케이블 하나가 잘못 연결된 탓에 중세로 회귀한다.
평화로운 마을에 정착한 것도 잠시, 곡식 9할을 뜯어 가는 **발드릭 영주**가 대군을 이끌고 침공해 오는데…

> “방패? 7.62mm 철갑탄 앞에서는 그냥 등산 스틱이지.”
> “마법이 아니라 열역학 제2법칙입니다.”

오프닝·스테이지 진입·보스·유물·재회귀마다 컷신이 재생되며, 로비의 **스토리 다시보기**에서 언제든 다시 볼 수 있습니다.

---

## 핵심 시스템

### 1. 스테이지 · 웨이브
- 각 스테이지 = 8 웨이브. 스테이지를 클리어하면 **다음 스테이지**로 진행하거나 로비에서 원하는 스테이지를 선택할 수 있습니다.
- 스테이지가 오를수록 적의 체력·공격력·방어력·물량이 **완만하게** 상승하고, 상위 병종(궁병→기병→공성추→투석기→중장갑 기사→공성탑→군주)이 순차 등장합니다.
- 웨이브마다 1~4개 방향에서 몰려오며, 미니맵과 화면 가장자리 화살표로 진입 방향을 예고합니다.
- 준비 시간 16~30초. 준비 중 **웨이브 시작**을 누르면 즉시 시작합니다.

### 2. 마을 · 방어 슬롯
- 중앙에 시청(성채), 민가, 창고, 대장간, 예배당, 시장, 우물이 있는 마을과 4개의 성문이 있습니다.
- 방어 슬롯(기본 8칸, 연구·재회귀 영구 강화로 최대 16칸)에 현대 병기를 배치합니다.
- 포탑은 Lv.1~10까지 강화(피해 +24%/Lv, 사거리·내구도 증가)하고 철거하면 건설비의 60%를 돌려받습니다.
- 성벽은 4방향별 내구도를 가지며 뚫리면 적이 마을 안으로 쏟아집니다. 웨이브 사이 자동 수리 + 긴급 수리.

### 3. 포탑 14종
개틀링 · 중기관총 · 박격포 · 화염방사기 · 유탄발사기 · 대물 저격 · 자주포 · 레이저 · 레일건 · 미사일 포대 · EMP · 냉동 분사 · 테슬라 코일

각 포탑은 탄환/곡사/유도/광선/관통/연쇄/감속 등 고유 메커니즘을 가집니다.

### 4. 기술 트리 (52 노드)
- **탄도·화기 / 폭발·포병 / 첨단·에너지 / 기지·성벽·경제** 4개 카테고리, 선행 노드가 선으로 연결된 인터랙티브 트리.
- 각 노드는 최대 5레벨까지 강화되며 피해·공속·사거리·폭발·관통·치명타·화상, 병기 해금, 슬롯 확장 등을 제공합니다.
- 연구 포인트(📘)는 웨이브 클리어·보상으로 획득. 재회귀하면 일반 연구는 초기화됩니다.

### 5. 재회귀(Prestige) · 영구 강화
- 스테이지 1 클리어 이후 언제든 재회귀 가능. 골드·포탑·일반 연구를 초기화하고 **회귀석(💎)**을 정산받습니다.
- 회귀석으로 **영구 강화 18종**(시작 골드·시작 연구·영구 화력/공속/사거리/치명타/관통/폭발·기지·성벽 내구도·자동 수리·슬롯·무료 포탑·연구 유지 등)을 구매합니다.
- 영구 강화는 재회귀해도 유지됩니다.

### 6. 고대 유물 (26종)
- 적 처치 시 **아주 낮은 확률**(일반 0.065%, 정예·공성 5배, 보스 25배)로 드롭됩니다.
- 일반/희귀/영웅/전설 4등급, 고유 영구 버프(치명타·사거리·골드·회귀석·관통·화상·감속 등).
- **재회귀해도 영구 보존**되며, 로비 **유물 도감**에서 보유 현황을 확인할 수 있습니다. 중복 획득은 회귀석으로 변환됩니다.

### 7. 숨겨진 치트 패널
- 여는 법: 로비의 버전 배지를 **5회 연속 탭** 또는 **Ctrl + Shift + C**
- 골드·연구 포인트·회귀석 즉시 수정, 웨이브/스테이지 점프, 전체 처치, 기지 무적, 즉시 클리어, 전체 연구 해금, 유물 강제 지급·드롭 확률 배율(×50~×5000) 등 테스트 기능.

- 기본 카메라 줌 (넓게 / 보통 / 가깝게)

- 데미지 숫자 표시 ON/OFF

- 효과음 ON/OFF

모든 옵션은 자동 저장됩니다.

## 기술 메모
- 순수 HTML/CSS/JavaScript + Canvas 2D. 빌드 도구·외부 라이브러리 없음.
- 아이소메트릭 타일(64×32) 위에서 깊이 버킷 정렬로 건물·유닛·성벽을 합성.
- 적 유닛은 객체 풀 + 공간 해시(Spatial Grid)로 수천 단위까지 처리.
- Web Audio API 기반 절차적 효과음(외부 음원 없음).
- 컷신은 Canvas 애니메이션 배경 + DOM 대화창(타자기 연출).
